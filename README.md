# Sortd (ソートド) - デスクトップ整理の究極ツール

Sortdは、散らかりがちなデスクトップを一瞬で整理整頓するための、軽量・高速なデスクトップ専用ユーティリティです。Tauri v2とRustで構築されており、セキュリティとパフォーマンスを両立しています。

## ✨ 主な機能

### 1. 「新しいフォルダー」の一括削除
デスクトップに溜まりがちな、中身が空だったり仮で作っただけの「新しいフォルダー」をワンクリックで全てスキャンし、一括削除します。

### 2. 拡張子別の自動フォルダ整理
デスクトップにあるファイルを拡張子（.pdf, .jpg, .exeなど）ごとに自動でフォルダ分けします。
- **ショートカット保護:** Windowsのショートカット（.lnk）やWebサイトへのリンク（.url）は移動せず、デスクトップに残したままにします。
- **カスタム接頭辞:** 整理用フォルダに「◇」などの接頭辞を付けられるため、元のフォルダと混ざる心配がありません。
- **プレビュー機能:** 実行前に、どのファイルがどのフォルダに移動されるかを確認できる安全設計です。

### 3. 内容に応じたプロジェクト分類
バラバラに置かれたフォルダの中身をAIのように賢く分析し、その種類に応じて分類します。
- **WebProject:** HTML, PHP, JSなどが含まれるフォルダ
- **UnityProject:** Unityのプロジェクトファイルが含まれるフォルダ
- **DesignProject:** PSD, AIファイルなどが含まれるフォルダ
- **ProgrammingProject:** C++, Java, Rustなどのソースコードが含まれるフォルダ
- **Memo:** テキストファイルのみが含まれるフォルダ
- その他、DocumentProjectやProjectWorking（Excelと画像が混在する作業用）など、独自のルールで分類します。

### 4. 魔法の「元に戻す (Undo)」
「間違えて整理してしまった！」という時も安心です。前回の整理操作を1回分、完全に元の場所へ戻すことができます。

### 5. システム親和性
- **ライト/ダークモード対応:** Windowsのシステム設定に合わせて、自動的に画面テーマが切り替わります。
- **コンパクト設計:** 画面を占領しない小さなウィンドウで、必要な時にサッと起動して使えます。

## 🚀 技術スタック
- **Backend:** Rust (Tauri v2)
- **Frontend:** HTML, JavaScript, Tailwind CSS, DaisyUI
- **Packaging:** NSIS (Windows Installer) - 日本語完全対応
