# Sortd (ソートディ) - デスクトップ整理の究極ツール

Sortdは、散らかりがちなデスクトップを一瞬で整理整頓するための、軽量・高速なデスクトップ専用ユーティリティです。Tauri v2とRustで構築されており、セキュリティとパフォーマンスを両立しています。

## ✨ 主な機能

### 1. 「新しいフォルダー」の一括削除
デスクトップに溜まりがちな、中身が空だったり仮で作っただけの「新しいフォルダー」をワンクリックで全てスキャンし、一括削除します。

### 2. 拡張子別の自動フォルダ整理
デスクトップにあるファイルを拡張子（.pdf, .jpg, .exeなど）ごとに自動でフォルダ分けします。
- **ショートカット保護:** Windowsのショートカット（.lnk）やWebサイトへのリンク（.url）は移動せず、デスクトップに残したままにします。
- **プレビュー機能:** 実行前に、どのファイルがどのフォルダに移動されるかを確認できる安全設計です。

### 3. 内容に応じたプロジェクト分類
バラバラに置かれたフォルダの中身を分析し、その種類に応じて自動分類します。
デフォルトでWeb、Unity、Python、デザインなどのプロジェクトルールが設定されていますが、**設定画面から分類ルールを自由に追加・削除**することができます。
さらに、これらのカスタムルールは**JSONファイルとしてインポート・エクスポート**が可能です。

### 4. 今日のファイルを整理
本日更新されたファイルだけを抽出し、指定した名前のフォルダへ一括で移動します。日々の作業ファイルの一時退避に便利です。

### 5. 重複ファイルを削除
デスクトップ上に散乱しがちな「〜のコピー」や「(1)」といった接尾辞が付いた重複ファイルをスキャンし、元のファイルが存在する場合にのみ安全に一括削除します。

### 6. ごみ箱を空にする
デスクトップ整理の仕上げに、ごみ箱を完全に空にすることができます。実行前に、ごみ箱の中身の合計サイズが表示されます。

### 7. 魔法の「元に戻す (Undo)」
「間違えて整理してしまった！」という時も安心です。前回の整理操作（ファイルの移動、フォルダの分類）を、完全に元の場所へ戻すことができます。
※「新しいフォルダー」の削除および「ごみ箱を空にする」操作は元に戻せません。

### 8. 高度な設定と除外リスト
- **除外設定:** 整理したくない特定のフォルダやファイルを、パスを指定して除外リストに追加できます。
- **カスタム接頭辞:** 整理用フォルダ（例：◇EXE）の「◇」部分を自由に変更可能です。
- **テーマ選択:** 任意のカスタムカラーを設定できるほか、16種類のプリセットカラーからお好みのテーマを選択できます。
- **UIレイアウト:** 広々としたグリッドレイアウトを採用。
- **システム同期:** システムのライト/ダークモード設定に合わせて自動でUIが最適化されます。

## 🚀 技術スタック
- **Backend:** Rust (Tauri v2)
- **Frontend:** SvelteKit, Tailwind CSS
- **Packaging:** NSIS (Windows Installer) - 日本語完全対応

